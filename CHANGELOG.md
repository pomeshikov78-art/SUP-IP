# Журнал версий СУП-ИП

Формат: после каждой операции (изменения программы) фиксируется новая версия,
копия README сохраняется в `versions/README-vX.Y.Z.md`, изменения пушатся в
https://github.com/pomeshikov78-art/SUP-IP.

## v1.3.0 — 2026-11-24
- Документооборот по ТЗ §25: серверный генератор DOCX/XLSX/PDF/CSV/HTML (docgen.py, только stdlib, встроенные шрифты с кириллицей, векторные диаграммы, колонтитулы и нумерация страниц, автофильтры и формулы XLSX), выгрузка 12 видов документов из M01/M02/M04/M05/M06/M08/M10/M13/M15/M16/M17, протокол совещания по §2.8 с регистрацией DOCX+PDF в M09, кнопки выгрузки в клиенте, 141 новый тест (47 docgen + 94 export)
